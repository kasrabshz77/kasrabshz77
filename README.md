## What I'm Building

### MoneyMind — Context-Aware Personal Finance Copilot
A collaborative AI personal finance application that uses spending data, user context, goals, and budgets to provide more relevant financial guidance.

**Stack:** React 19, Vite, TypeScript, Tailwind CSS, FastAPI, MongoDB Atlas, Atlas Vector Search, Voyage AI, LangGraph, Gemini, Clerk

- Separate frontend, backend, and agent services
- MongoDB Atlas for financial data and contextual memory
- Financial statement ingestion and context-aware agent workflows
- Focus on personalized guidance backed by reliable data processing and evaluation

**Explore:** [MoneyMind showcase](https://github.com/kasrabshz77/moneymind-showcase) · [Vercel preview](https://money-mind-prod.vercel.app)

*The actively developed production repository is private.*

### JARVIS — Explainable Task Reasoning System
A full-stack task-management application that explains blockers and readiness with symbolic reasoning, stored dependencies, and inspectable evidence paths.

**Stack:** Python, FastAPI, SWI-Prolog, Janus, SQLite, React, TypeScript

- Persistent task management and cycle-safe dependency editing
- Prolog reasoning for direct and underlying blockers, with a visual dependency graph and **Why?** explanations
- Bounded execution, recovery checks, independent reasoning tests, and real-browser integration verification

**Explore:** [JARVIS showcase](https://github.com/kasrabshz77/jarvisAi-showcase)

*Private development repository; conversational AI and voice capabilities are planned.*
